# MedCloud 360
### Enterprise GCP-First Hybrid Cloud Platform

**Stack:** Google Cloud · Azure · Terraform · Palo Alto VM-Series · VMware / Proxmox · Security · Analytics & AI

## Overview

MedCloud 360 is an independent, GCP-first enterprise cloud engineering project demonstrating governed infrastructure, secure hybrid connectivity, workload modernization, operational resilience, and analytics. All healthcare-style data is **synthetic**.

## Engineering principles

Terraform-managed infrastructure, least-privilege access, reviewed changes, tested controls, operational runbooks and cost governance. This is a **portfolio project**, not an official Vitalant environment. Do not publish credentials, state, personal identifiers or real patient data. Security control mapping does not imply HIPAA certification.
